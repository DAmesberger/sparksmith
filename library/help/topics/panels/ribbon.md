Switch between Component, Schematic and PCB to see the commands for that workspace. Within PCB, Layout and 3D offer different view controls for the same board.

Hover a button to read its purpose and any assigned key. Use {key:app.help} on a button to open its topic. Arming a tool such as Route or Wire replaces Properties with the tool’s controls. Return to Select when you want to inspect an object.

Use the [[term/command-palette]] when you know a command’s name but cannot see its button.
