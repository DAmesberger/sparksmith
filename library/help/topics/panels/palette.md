Press {key:app.palette} and enter a command name or keyword. With an empty field, recent commands appear first. Each command row shows its context and effective key. A disabled row explains what the command needs.

Use the arrow keys to move through available results and Enter to run one. Escape closes the palette. Choose a Help result to read a topic. For parts and component values use the Schematic Place palette, described in [[guide/libraries]].

A [[term/command-palette]] result runs the same command as its ribbon or menu item.
