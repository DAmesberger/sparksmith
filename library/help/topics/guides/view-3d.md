Layout and 3D show the same board.

- In PCB, choose the 3D tab, or press {key:pcb.toggle-3d}.
- Drag with the right mouse button to turn the board, with the middle button to move it. The wheel zooms. {key:view.fit} shows the whole board.
- Click a face of the cube to look from that side.
- Select a part to see it in Properties. Go back with the Layout tab.

[[command/file.export]] in the File menu writes the board as a .solidcraft model.
