- Press {key:app.palette} and type a command's name. Enter runs it. A dim row says why it cannot run now.
- Press {key:app.shortcuts} to see every key.
- To change a key, open Settings with {key:app.settings}, choose Keyboard, and click the key. Press the new one; Esc cancels.
- If another command has that key, Swap exchanges them. Reset puts back the default.
