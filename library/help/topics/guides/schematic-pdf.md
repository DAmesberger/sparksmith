- Choose [[command/file.export-schematic-pdf]] in the File menu, or find it in the command palette with {key:app.palette}.
- Choose a file name. Each sheet is one page.

Board drawings come with the production files: tick PDF drawings under Files. See [[guide/fab-output]].
