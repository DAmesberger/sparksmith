The original board starts from the shipped new-project data and the fabrication profile named in `start.json`. The loader matches the board-chat regression. Every run writes `start.sparksmith` in its private output folder using the production project writer. The task digest includes the instantiated document, so changing the shipped defaults changes the digest.

The verifier reopens the result, resolves component and package revisions, checks the series circuit and return pour, renders the schematic and checks board findings. The board-chat regression also checks its exact scripted track and warning counts.

Run `cargo xtask agent-bench scripted board-build NEW_DIR line` for the lines-first scenario. Before its first edit the script compares the same entry from a find hit and a line-mode description. The independent verifier checks the resulting saved board against the board-build task. Use a fresh run directory.
