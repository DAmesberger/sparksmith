2. Layout: the marks on three focused layers

Five vias of the six-layer board. The ring takes the focused layer's colour. A through via keeps today's plain hole. Any other span splits the hole as the barrel does: upper half the first layer, lower half the last. A notched ring is a laser via, a cross is filled and capped, and a dashed outline does not reach this layer. L2 is Inner 1.

4. Order notes

A file of the release, usb-c-multitool-order-notes.txt.

ORDER NOTES                                  release 3f9c1d20a7b45e68
JLCPCB 4-layer · 4 copper layers · 0.8 mm

On the order form
  Base material      FR-4. No HDI: every via passes through the board.
  Via size           0.15 mm hole / 0.25 mm diameter
  Via covering       Epoxy Filled & Capped       (form label not verified)

Write in the remarks
  Fill with epoxy and cap: all vias of 0.15 mm finished hole
  (drill tool T1, 4 holes, in the pads of J1 B2, B3, B10, B11).
  All other vias (tools T2, T3) are tented and not filled.

JLCPCB asks for this: "For epoxy-filled vias, please leave a note …
Alternatively, you can specify to fill all vias of a particular diameter."
  jlcpcb.com/help/article/pcb-via-covering, read 2026-11-24

Surcharges JLCPCB publishes for this board, without amounts
  "0.1mm or 0.15mm hole size with any size via diameter … will cost more."
    jlcpcb.com/capabilities/pcb-capabilities, read 2026-11-24
